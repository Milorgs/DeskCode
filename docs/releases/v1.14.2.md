# DeskCode 1.14.2

此版本修复了 Landlock 沙箱在无 Landlock 内核环境下的兼容性及若干指令细节：

- 在未开启或不支持 Landlock 的 Linux 内核、WSL2 或受限容器环境中，命令不再因沙箱不可用而直接退出 126，行为与 `desk doctor` 保持一致；当内核支持 Landlock 但规则创建或应用异常时，仍会停止执行命令并报错。
- 自定义斜杠指令保留名补充 `sandbox`，避免工作区模板覆盖内建 `/sandbox` 指令。
- 同步更新 Linux `run_shell` 工具说明、`desk --help`（`--no-sandbox`）与对话内 `/help`（`/sandbox`）帮助文案，并加固 `tests/mcp_http.py` 退出子菜单时的终端输入同步。

---

This release fixes Landlock sandbox compatibility on Linux kernels without Landlock and cleans up command/help details:

- On Linux kernels, WSL2, or restricted containers where Landlock is unavailable, shell commands no longer exit 126 due to missing kernel support, matching `desk doctor`; when Landlock is supported by the kernel, any failure to create or apply rules still stops command execution with an error.
- Reserved `sandbox` in custom slash commands so workspace templates cannot shadow the built-in `/sandbox` command.
- Updated the Linux `run_shell` tool description, `desk --help` (`--no-sandbox`), and in-chat `/help` (`/sandbox`), and tightened PTY input synchronization in `tests/mcp_http.py`.
