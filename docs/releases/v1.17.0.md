# DeskCode 1.17.0

此版本补齐顶流编程智能体的最后三块版图：**可写并行子代理与 Git Worktree 隔离**、**VS Code 原生扩展 + 五架构发行包与主流包管理器清单**，以及 **终端与桌面 GUI 自动化动态演示与排行榜生成工具**。

- **可写并行子代理 + Git Worktree 隔离 + 自定义角色（`delegate_task`、`subagent_output`、`/agents`）**：
  - **内置与自定义子代理**：内置可写编码子代理 `coder` 与只读调研子代理 `research`；自动扫描工作区 `.deskcode/agents/*.md`、`.claude/agents/*.md`、用户配置目录 `agents/` 及已启用插件中的 `agents/*.md`（支持 `name`、`description`、`tools` 白名单与 Claude 工具名映射、`readonly`、`isolation: worktree`、`model` 配置名覆盖与 `max_steps`）。
  - **独立 Git Worktree 分支隔离（`worktree=true`）**：在临时 Git worktree（`desk/<agent>-<id>`）中运行子代理，文件修改与 Linux Landlock 沙箱严格隔离在各自 worktree 内；无改动时自动清理目录与临时分支，有改动时自动剔除 `.desk-agent/` 内部缓存、提交到独立分支并释放临时目录，返回 `branch`、`commit`、`changed_files` 与 `diff_stat` 供主代理一键 `git merge`。
  - **后台真并行（`background=true`）**：单次可并发启动最多 4 个独立子代理线程（比如同时重构模块与编写测试），通过 `subagent_output` 收集结果并将词元与费用汇总回当前对话。
- **VS Code 原生扩展（`editors/vscode/`）与 `.vsix` 安装包**：
  - 零第三方运行时依赖的原生 VS Code 扩展（`deskcode-vscode`），基于 `desk acp` 提供侧边栏流式对话面板、`Ask / Edit / Full / Plan` 四档模式切换、实时工具状态卡片与任务清单、内联权限审批按钮、一键打开 VS Code 原生双栏 Diff 对比视图，以及右键菜单选中代码提问（`Ask About Selection`）与一键修复当前文件诊断报错（`Fix Problems in Active File`）。Release 随附预打包 `deskcode-vscode-1.17.0.vsix`。
- **五架构预编译包（新增 `Linux arm64` 与 `Windows arm64`）与四大包管理器（`packaging/`）**：
  - CI 与 GitHub Release 现同步构建并发布 **Linux x64**、**Linux arm64 (`aarch64`)**、**Windows x64**、**Windows arm64** 与 **macOS Universal (`arm64 + x86_64`)** 五大架构原生包，`install-linux.sh`、`install-windows.ps1`、GitHub Action 与 Harbor 评测容器安装脚本均自动识别架构。
  - 新增 `packaging/`，提供 **Homebrew**（`deskcode.rb`）、**Scoop**（`deskcode.json`）、**WinGet**（`Milorgs.DeskCode.yaml`）与 **Arch Linux AUR**（`PKGBUILD` / `.SRCINFO`）清单及自动哈希更新工具 `packaging/update_checksums.py`。
- **动态演示素材与跑分排行榜工具（`docs/assets/`、`bench/render_leaderboard.py`）**：
  - 新增高清矢量动态演示图（并行 Git Worktree + LSP 自动诊断自修、原生桌面无障碍 GUI 自动化）与 GIF 动图，并提供 `bench/render_leaderboard.py` 将本地多模型跑分 JSON 一键渲染为对比榜单。

---

This release completes three major capabilities: **writable parallel subagents with Git worktree isolation**, a **native VS Code extension + 5-platform (`x64` & `arm64`) releases & package manager manifests**, and **visual workflow demos + benchmark leaderboard tooling**.

- **Writable Parallel Subagents, Git Worktree Isolation & Custom Agents (`delegate_task`, `subagent_output`, `/agents`)**:
  - **Built-in & Custom Agents**: Ships with `coder` (writable) and `research` (read-only), plus automatic discovery of `.deskcode/agents/*.md`, `.claude/agents/*.md`, user `agents/`, and plugin `agents/*.md` (supporting `name`, `description`, `tools` allowlists with Claude tool-name aliases, `readonly`, `isolation: worktree`, `model` profile overrides, and `max_steps`).
  - **Git Worktree Isolation (`worktree=true`)**: Runs each subagent inside a temporary git worktree on branch `desk/<agent>-<id>`. Unchanged worktrees and branches are cleaned up automatically; changed worktrees strip internal `.desk-agent/` scratch files, commit onto the branch, remove the checkout directory, and return `branch`, `commit`, `changed_files`, and `diff_stat` ready for `git merge`.
  - **Parallel Background Execution (`background=true`)**: Launch up to 4 concurrent subagents in parallel and await results with `subagent_output`, rolling token usage and cost back into the parent session.
- **Native VS Code Extension (`editors/vscode/`) & Pre-built `.vsix`**:
  - Zero-dependency VS Code extension (`deskcode-vscode`) powered by `desk acp`—featuring a streaming sidebar chat view, `Ask / Edit / Full / Plan` switcher, live tool cards and checklists, inline permission buttons, native side-by-side `vscode.diff` inspection, `Ask About Selection`, and `Fix Problems in Active File`. Published as `deskcode-vscode-1.17.0.vsix` on GitHub Releases.
- **5-Platform Releases (`Linux arm64` & `Windows arm64` added) + Package Managers (`packaging/`)**:
  - Release builds now cover **Linux x64**, **Linux arm64 (`aarch64`)**, **Windows x64**, **Windows arm64**, and **macOS Universal (`arm64 + x86_64`)**, with automatic architecture detection in `install-linux.sh`, `install-windows.ps1`, the GitHub Action, and the Harbor container installer.
  - Added `packaging/` manifests for **Homebrew** (`deskcode.rb`), **Scoop** (`deskcode.json`), **WinGet** (`Milorgs.DeskCode.yaml`), and **Arch Linux AUR** (`PKGBUILD` / `.SRCINFO`), plus `packaging/update_checksums.py`.
- **Visual Demos & Leaderboard Renderer (`docs/assets/`, `bench/render_leaderboard.py`)**:
  - Added animated terminal & desktop GUI automation showcases in `docs/assets/` and `bench/render_leaderboard.py` to generate Markdown leaderboards from `bench/results/*.json`.
