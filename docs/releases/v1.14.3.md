# DeskCode 1.14.3

此版本新增 macOS 持续集成测试与 Universal 2（Apple Silicon + Intel）预编译安装包分发，并统一三端发布流程：

- **新增 macOS Universal（`arm64` + `x86_64`）预编译安装包与一行安装脚本**：发布页同步提供 `desk-agent-macos-universal.tar.gz`（已静态链接 `json-c`、`OpenSSL 3` 与 `GNU Readline 8`，仅依赖 macOS 系统基础库，无需安装 Homebrew 运行时），Apple Silicon 与 Intel Mac 均可通过 `install-macos.sh` 一行安装。
- **新增 GitHub Actions macOS 自动化构建与端到端测试**：每次提交在真实 macOS 环境完整执行单测、进程/PTY 回归与 MCP Streamable HTTP 集成测试，Release 标题统一更新为 `Windows / Linux / macOS`。
- **改进 macOS 路径与环境细节**：兼容 macOS 系统根符号链接目录（`/tmp`、`/var`、`/etc`），优化 `desk doctor` 在 macOS（`System Events`）与 Windows（`UI Automation`）下的桌面支持状态展示，以及本地 `stdio` MCP 子进程环境变量构造安全性。

---

This release adds native macOS CI testing, Universal 2 (`arm64` + `x86_64`) prebuilt macOS binary distribution, and unified three-platform release packaging:

- **Prebuilt macOS Universal (`arm64` + `x86_64`) release archive & one-line installer**: GitHub Releases now ship `desk-agent-macos-universal.tar.gz` (statically linked with `json-c`, `OpenSSL 3`, and `GNU Readline 8` so no Homebrew runtime libraries are needed) along with `install-macos.sh` for both Apple Silicon and Intel Macs.
- **GitHub Actions macOS CI & unified release titles**: Every push now runs the full unit, PTY, and MCP Streamable HTTP integration suite on macOS and publishes releases under `Windows / Linux / macOS`.
- **macOS portability refinements**: Handled macOS root firmlinks/symlinks (`/tmp`, `/var`, `/etc`) in directory creation, reported platform-accurate desktop automation backends (`System Events` on macOS, `UI Automation` on Windows) in `desk doctor`, and hardened POSIX `stdio` MCP child environment setup.
