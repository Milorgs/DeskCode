# DeskCode 1.16.0

此版本补齐现代编程智能体的四项核心生态能力：**LSP 编译器级代码诊断与导航**、**IDE 接入（Agent Client Protocol `desk acp`）**、**Skills 与插件生态（兼容 Claude Code 插件包）**，以及 **GitHub Action 与 Python SDK**。

- **LSP 代码诊断与导航（`lsp` 工具 + 自动诊断回传）**：自动探测本机 `PATH` 上的 `clangd`、`pyright-langserver` / `basedpyright-langserver` / `pylsp`、`typescript-language-server`、`gopls`、`rust-analyzer`（并可通过用户配置目录 `lsp.json` 自定义或覆盖，`DESK_NO_LSP=1` 可关闭）。`write_file` / `edit_file` / `multi_edit` 写入成功后自动同步文件并将最新编译错误与警告（`diagnostics` / `diagnostics_summary`）附带返回给模型实现即时自修；同时提供只读 `lsp` 工具，支持 `diagnostics`、`definition`、`references`、`hover` 与 `symbols`（自动完成 UTF-16 与 UTF-8 字符列号转换）。
- **IDE 接入（`desk acp` — Agent Client Protocol）**：内置标准输入/输出 JSON-RPC 2.0 ACP v1 服务端，可直接配置进 **Zed**、**JetBrains IDEs** 等支持 ACP 的编辑器。完整支持 `initialize`、`session/new`（工作区 `cwd`、前端透传 `mcpServers` 与 `ask` / `edit` / `full` / `plan` 四种模式）、`session/set_mode`、`session/prompt`（文本、`resource_link` 工作区引用与内嵌 `resource` 上下文）、实时 `session/update`（流式回复分片、工具调用、文件修改 `diff` 与 LSP 诊断摘要、`todo_write` 任务清单 `plan`）以及双向 `session/request_permission` 权限审批与 `session/cancel` 中途取消。
- **Skills 技能与插件包生态（`skill` 工具、`/skills`、`/plugins`、`desk plugin`）**：
  - **Skills（`SKILL.md`）**：自动扫描工作区 `.deskcode/skills`、`.claude/skills`、`.agents/skills`、用户配置目录 `skills` 及已启用插件，仅在存在技能时按需注册 `skill` 工具（保持默认零系统提示词污染），支持读取技能目录内的配套参考文件与 `/<技能名> [需求]` 直接调用。
  - **插件管理（`desk plugin`）**：支持 `list`、`install`（本地目录、Git 地址、`owner/repo` 或 `.claude-plugin/marketplace.json` 插件市场）、`update`、`enable`、`disable`、`remove` 与 `validate`；无缝兼容 Claude Code 插件目录结构（`commands/`、`skills/`、`hooks/hooks.json`、`.mcp.json` 及 `${CLAUDE_PLUGIN_ROOT}` / `${DESK_PLUGIN_ROOT}` 路径展开）。
  - **钩子格式扩展**：除原有 `pre_shell` / `post_edit` 外，原生兼容 Claude 风格 `PreToolUse` / `PostToolUse` 钩子配置（标准输入传入 JSON 事件，退出码 `2` 拦截操作并向模型反馈原因）。
- **GitHub Action（`action/`）与 Python SDK（`sdk/python/`）**：
  - **GitHub Action（`Milorgs/DeskCode/action@main`）**：支持在 Issue、PR 评论或 `workflow_dispatch` 中通过 `@desk` 触发，自动校验协作者写权限、防 bot 自触发、隔离并脱敏密钥，完成后自动推送分支并创建 PR（fork PR 仅安全评论不推送）或以 `--plan` 只输出方案。
  - **Python SDK（`deskcode`）**：零第三方依赖（Python 3.9+ 标准库），同时提供单次无头 `run()` / `arun()` 与基于 `desk acp` 的流式多轮会话客户端 `DeskAgent` / `AsyncDeskAgent`（支持自定义权限审批回调、资源附带与事件流迭代）。

---

This release completes four ecosystem pillars—**compiler-grade LSP diagnostics & code navigation**, **IDE integration via Agent Client Protocol (`desk acp`)**, **Skills & Claude Code-compatible plugins**, and an official **GitHub Action + Python SDK**.

- **LSP Diagnostics & Navigation (`lsp` tool + automatic post-edit diagnostics)**: Automatically discovers `clangd`, `pyright-langserver` / `basedpyright-langserver` / `pylsp`, `typescript-language-server`, `gopls`, and `rust-analyzer` on `PATH` (customizable via `<config_dir>/lsp.json`; disable with `DESK_NO_LSP=1`). Successful `write_file`, `edit_file`, and `multi_edit` calls sync the file and attach compiler errors and warnings (`diagnostics` / `diagnostics_summary`) directly to the tool result; the read-only `lsp` tool exposes `diagnostics`, `definition`, `references`, `hover`, and `symbols` with UTF-16 <-> UTF-8 column conversion.
- **IDE Integration (`desk acp` — Agent Client Protocol)**: Speaks newline-delimited JSON-RPC 2.0 ACP v1 over stdio for **Zed**, **JetBrains IDEs**, and custom clients—supporting `initialize`, `session/new` (`cwd`, `mcpServers`, and `ask` / `edit` / `full` / `plan` modes), `session/set_mode`, `session/prompt` (`text`, `resource_link`, and embedded `resource` blocks), live `session/update` notifications (streamed text chunks, tool calls, file `diff` + LSP diagnostics summaries, and `todo_write` `plan` entries), interactive `session/request_permission` round-trips, and `session/cancel`.
- **Skills & Plugin Ecosystem (`skill` tool, `/skills`, `/plugins`, `desk plugin`)**:
  - **Skills (`SKILL.md`)**: Discovers skills across `.deskcode/skills`, `.claude/skills`, `.agents/skills`, user `skills/`, and enabled plugins—exposing the `skill` tool (with bundled relative-file reading) and `/<skill> [request]` slash expansion without injecting extra system prompts when no skills exist.
  - **Plugin Manager (`desk plugin`)**: `list`, `install` (from local directories, Git URLs, GitHub `owner/repo`, or `.claude-plugin/marketplace.json`), `update`, `enable`, `disable`, `remove`, and `validate`, compatible with Claude Code plugin bundles (`commands/`, `skills/`, `hooks/hooks.json`, `.mcp.json`, and `${CLAUDE_PLUGIN_ROOT}` / `${DESK_PLUGIN_ROOT}` expansion).
  - **Claude-Style Hooks**: `hooks.json` now also accepts `PreToolUse` and `PostToolUse` matchers receiving event JSON on `stdin` (exit code `2` blocks the tool call and returns `stderr` to the model).
- **GitHub Action (`action/`) & Python SDK (`sdk/python/`)**:
  - **GitHub Action (`Milorgs/DeskCode/action@main`)**: Responds to `@desk` in issues, PR comments, review comments, or `workflow_dispatch`—verifying collaborator write permissions, preventing bot self-triggers, redacting secrets, and automatically pushing commits and opening PRs (comment-only on fork PRs and in `plan: true` mode).
  - **Python SDK (`deskcode`)**: Zero external dependencies (Python 3.9+ stdlib), providing one-shot `run()` / `arun()` and streaming ACP sessions via `DeskAgent` / `AsyncDeskAgent`.
