# DeskCode 1.18.1

## 中文

- 添加模型时，服务商、模型列表和保存确认分屏显示。窄窗口会缩短过长的默认地址，回车仍使用完整地址。
- 保存前可核对模型 ID、接口类型和地址。填写完整的 OpenAI 或 Anthropic 请求地址时，向导会先校验并整理地址。
- 修复在终端粘贴 API Key 时，粘贴标记或多余换行被当作密钥内容的问题。

## English

- The add-model wizard now separates provider selection, model selection and save confirmation. Narrow terminals shorten long default URLs on screen while retaining their full values.
- Review the model ID, protocol and URL before saving. The wizard validates and normalizes full OpenAI and Anthropic endpoint URLs before requesting a key.
- Fixed terminal paste markers and stray newlines being included in pasted API keys.
