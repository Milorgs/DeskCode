# DeskCode 1.15.0

此版本补齐日常好用度的关键能力：计划模式、任务清单、多步回退、后台命令与费用透明，并搭建可复现的 Agent 跑分体系。

- **计划模式（`Shift+Tab` / `/plan`、`/go`、`--plan`）**：计划模式下只向模型提供只读工具（读文件、搜索、代码大纲、调研子代理、网页、只读命令等）与 `submit_plan`，MCP 工具与文件修改全部停用；模型提交的方案以「计划（等待批准）」展示，`/go` 批准后退出计划模式并开始实施。无头模式 `desk --plan -p ...` 直接把方案作为回复输出，JSON 结果附带 `plan_submitted`。不注入任何系统提示词，行为完全由工具定义描述。
- **任务清单 `todo_write`**：多步任务中模型可维护「待办 / 进行中 / 已完成」清单，每次更新都会在对话中显示进度。
- **多步回退 `/rewind`**：可选择回退到任意一条仍在上下文中的历史需求之前，同时撤回对话与该需求之后的文件改动（或仅回退对话），原需求自动放回输入框便于修改重发。若同一工作区内其他对话在之后修改过文件，为避免覆盖会拒绝回退文件。
- **后台命令**：`run_shell` 新增 `background` 参数用于开发服务器、监听器与长时间测试，配合 `shell_output` / `shell_kill` 查看与停止（最多 8 个，对话结束时自动清理）；Linux / macOS 下命令执行中按 `Ctrl+B`（或 `/bg`）可把前台命令转入后台，当前任务继续。
- **用量与费用透明（`/cost`、`/price`）**：词元按「输入 / 缓存命中 / 输出」拆分统计（兼容 OpenAI `cached_tokens`、DeepSeek 缓存命中与 Anthropic 缓存读写）；`/price 输入价 输出价 [缓存价] [币种]` 为当前模型设置每百万词元单价后，状态栏、每轮结束行与 `/cost` 显示估算费用；OpenRouter 返回的 `usage.cost` 会被直接采用。JSON 结果新增 `usage` 字段。
- **Agent 跑分体系 `bench/`**：新增离线本地任务集与运行器（隔离配置目录、输出通过率 / 耗时 / 词元报告）以及 Terminal-Bench 2.0 / Harbor 适配器。

---

This release adds the everyday capabilities expected from a top coding agent—plan mode, checklists, multi-step rewind, background commands and cost transparency—plus a reproducible benchmark harness.

- **Plan mode (`Shift+Tab` / `/plan`, `/go`, `--plan`)**: Only read-only tools (file reads, search, outline, research subagent, web, read-only commands) and `submit_plan` are offered; MCP tools and file changes are disabled. The submitted plan is shown as "Plan (awaiting approval)" and `/go` leaves plan mode and starts implementing. Headless `desk --plan -p ...` prints the plan as the reply, and the JSON result includes `plan_submitted`. No system prompt is injected; behavior comes from the tool definitions.
- **Checklists with `todo_write`**: The model keeps a pending / in progress / completed list for multi-step work, shown in the conversation on every update.
- **Multi-step `/rewind`**: Rewind to before any request still in context, restoring the conversation and the file changes made since (or the conversation only); the request returns to the composer to edit and resend. File rewinds are refused when another conversation in the same workspace changed files afterwards, so its work is never overwritten.
- **Background commands**: `run_shell` accepts `background` for dev servers, watchers and long test runs, with `shell_output` / `shell_kill` to inspect and stop them (up to 8, cleaned up when the conversation ends). On Linux and macOS, `Ctrl+B` (or `/bg`) moves a running foreground command to the background while the turn continues.
- **Usage and cost (`/cost`, `/price`)**: Tokens are split into input / cache hits / output (OpenAI `cached_tokens`, DeepSeek cache hits and Anthropic cache reads/writes). After `/price IN OUT [CACHE] [CURRENCY]` sets per-million-token prices for the current model, the status bar, the end-of-turn line and `/cost` show an estimated cost; OpenRouter's `usage.cost` is used as reported. The JSON result gains a `usage` object.
- **Benchmark harness `bench/`**: An offline local task suite and runner (isolated configuration directories; pass rate, time and token report) and a Terminal-Bench 2.0 / Harbor adapter.
