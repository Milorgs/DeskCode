# DeskCode 1.12.0

补齐代码库语义理解、高频编码交互与多模态输入，并将终端交互体验统一对齐到 Windows。

- 代码结构大纲（`code_outline`）：零外部依赖提取 C/C++/Java/C#、Python、JS/TS、Go、Rust 源文件或目录树的命名空间、类、结构体、接口、枚举与函数签名及行号，模型无需盲读整份大文件即可快速定位。
- 项目指南自动注入：工作区根目录存在普通 UTF-8 文件 `AGENTS.md` 或 `CLAUDE.md` 时自动注入本轮上下文（可通过 `DESK_NO_PROJECT_GUIDE=1` 关闭），同时兼容 OpenAI 与 Anthropic 原生接口。
- 只读调研子任务（`delegate_research`）：在隔离的只读子上下文中组合调用 `list_files`、`code_outline`、`search_text`、`read_file` 查清跨文件问题，只将结论与查阅路径返回主对话，避免大量搜索输出挤占主会话预算。
- `@文件` 模糊补全与内联引用：输入框内键入 `@关键词` 按 `Tab` 可模糊补全或选择工作区文件；消息中的 `@path`、`@path:起-止` 自动附带受保护校验后的文件内容或行段，图片文件（PNG/JPEG/WebP/GIF）自动以多模态内容块发送。
- 剪贴板贴图与多行安全粘贴：按 `Ctrl+V`（Windows 为 `Alt+V`）或输入 `/paste` 直接附带系统剪贴板中的图片；开启终端 Bracketed Paste 后，粘贴多行代码或日志自动折叠为 `[粘贴 #1 · N 行]` 标签，不再因换行被误拆成多条请求，按 `Alt+Enter` 可在单行输入框插入换行。
- Windows 终端体验对齐：Windows 10/11 终端共享固定底部输入栏、右侧滚动条与鼠标滚轮/键盘滚动、顶部多对话并发状态栏、需求历史调出（`Ctrl+P`/`Ctrl+N`、`Alt+↑/↓`）以及实时思考计时、词元统计和上下文占用估算。

---

Deeper codebase understanding, faster coding interactions and multimodal input, with full terminal UI parity on Windows.

- Symbol outline (`code_outline`): zero-dependency symbol extractor for C/C++/Java/C#, Python, JS/TS, Go, and Rust files or directory trees, returning namespaces, classes, structs, interfaces, enums, and functions with 1-based line numbers so the model locates definitions without reading entire large files.
- Automatic project instructions: workspace `AGENTS.md` and `CLAUDE.md` files are loaded into the model context automatically (disable with `DESK_NO_PROJECT_GUIDE=1`) across both OpenAI-compatible and native Anthropic APIs.
- Read-only research subagent (`delegate_research`): investigates multi-file questions in an isolated read-only context (`list_files`, `code_outline`, `search_text`, `read_file`) and returns concise findings and inspected paths without filling the main conversation context.
- `@file` fuzzy completion and inline references: press `Tab` on `@query` in the chat input to fuzzy-complete or pick workspace files; `@path` and `@path:start-end` attach validated file contents or slices, and `@image` attaches PNG/JPEG/WebP/GIF images for both OpenAI and Anthropic vision models.
- Clipboard images and multiline bracketed paste: press `Ctrl+V` (`Alt+V` on Windows) or run `/paste` to attach an image from the system clipboard; multiline pastes fold into `[Paste #1 · N lines]` chips instead of submitting line by line, and `Alt+Enter` inserts a newline inside the single-row composer.
- Windows terminal parity: Windows 10/11 consoles now share the pinned bottom composer, proportional scrollbar, mouse-wheel and keyboard scrolling, live parallel conversation header, request history recall (`Ctrl+P`/`Ctrl+N`, `Alt+Up/Down`), live token counters, and estimated context usage.
