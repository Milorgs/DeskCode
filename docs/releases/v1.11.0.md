- 首次使用引导：没有模型时主菜单直接提示并默认选中「添加模型」。内置 OpenAI、Anthropic、DeepSeek、Kimi、通义千问、智谱 GLM、硅基流动、OpenRouter、Ollama 预设，只需填 API Key；配置时自动拉取服务商的在线模型列表供选择。
- 回复排版：模型回复按 Markdown 渲染（标题、列表、引用、粗体、行内代码、代码块、分隔线），流式输出也能实时排版；多行回复在 ● 下悬挂对齐。模型输出中的终端控制字符一律过滤。
- 审批面板显示 diff：编辑与覆盖文件时展示 `@@ 第 N 行 @@`、红色删除行、绿色新增行和 `+N −M 行` 统计，一眼看清改了什么。
- 命令面板：对话中按 `/` 打开，新增「清空上下文」「查看状态」「快捷键帮助」；新对话显示示例需求与快捷键。
- 无头与自动化：`desk -p -` 从标准输入读取需求；标准输出不是终端时只输出最终回复；`--json` 输出包含 status、reply、tokens、tools 的单个 JSON 结果；`--approval ask|edit|full` 控制批准；无终端时需要批准会明确返回 `approval_required`。
- `desk -c` 继续本目录最近的对话；`desk doctor [--json]` 逐项检查工作目录、模型、命令、桌面、MCP 和对话记录。
- 主菜单显示当前工作目录；帮助信息按用途分组。

- First-run guidance: with no model configured, the main menu says so and preselects Add model. Presets for OpenAI, Anthropic, DeepSeek, Kimi, Qwen, Zhipu GLM, SiliconFlow, OpenRouter and Ollama only need an API key, and the provider's live model list is offered during setup.

- Diff approvals: edits and overwrites show `@@ line N @@`, removed lines in red, added lines in green and a `+N −M lines` summary.
- Command palette: press `/` in a chat; it now includes Clear context, View status and Keyboard shortcuts. New chats show example requests and keys.
- Headless and automation: `desk -p -` reads the request from stdin; when stdout is not a terminal only the final reply is printed; `--json` prints one result object with status, reply, tokens and tools; `--approval ask|edit|full` sets approvals; a needed approval without a terminal returns `approval_required`.
- `desk -c` resumes the latest conversation in the workspace; `desk doctor [--json]` checks workspace, model, shell, desktop, MCP and history.
- The main menu shows the workspace; help is grouped by task.
