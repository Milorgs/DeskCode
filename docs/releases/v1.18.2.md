# DeskCode 1.18.2

## 中文

- 添加模型时，保存确认页默认选中直接保存。保存后，新模型会出现在首页并成为当前模型。
- 如果可选的连接测试失败，确认页会显示错误并保留已填写的配置，你可以重试或直接保存。

## English

- The add-model wizard defaults to saving the configuration. Once saved, the new model appears on the home screen and becomes active.
- If the optional connection test fails, the confirmation page shows the error and keeps the entered configuration so you can retry or save it.
