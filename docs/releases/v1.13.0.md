# DeskCode 1.13.0

全面补齐回滚安全网、大文件编辑、正则与 `.gitignore` 搜索、智能命令审批、长命令实时进度、受控网页读取、桌面多模态截图、Windows 本地 stdio MCP 与主动上下文压缩。

- 整轮文件一键撤回（`/undo`）与缓存自动清理：按轮记录首次文件备份与新建文件列表，输入 `/undo` 即可原子恢复上一轮修改并移除新建文件（即使单轮内对同一文件连续修改多次也能精准还原至轮前状态），并在每轮自动清理过期的未引用备份与剪贴板图片缓存。
- 大文件局部编辑上限提升至 4 MB：在 4 MB 以内的 UTF-8 文件上，`read_file` 分段读取同步返回整文件 `sha256`，`edit_file` 支持直接对超过 256 KB 的大型源码文件进行乐观锁校验编辑（`write_file` 整文件写入仍保持 256 KB 防误覆写上限）。
- 正则、文件通配符与 `.gitignore` 感知搜索：`search_text` 新增 `regex`（ECMAScript 正则，带单行长度保护）与 `file_pattern`（支持 `*`、`?`、`{a,b}` 通配符）参数；`search_text`、`code_outline` 与 `@文件` 补全自动解析并遵循工作区 `.gitignore` 规则。
- 更细粒度的命令审批策略：「帮我批准」（`--approval edit`）模式下自动放行经严格语法校验的无副作用只读检查命令（如 `git status`/`diff`/`log`、`ls`、`pwd`、`rg` 等，拒绝一切管道、重定向与命令拼接）；默认模式下每次命令审批新增 `[4] 本对话允许同类` 选项，记住当前会话允许的命令前缀。
- 长耗时命令实时输出尾部进度与 `web_fetch` 网页读取：运行超过 0.35 秒的编译或测试命令实时采样最新输出行展示在底部状态栏或进度行；新增受审批保护的 `web_fetch` 工具，内置 DNS 私网/环回地址 SSRF 拦截、`CURLOPT_RESOLVE` 地址绑定与 HTML 正文提取。
- 桌面自动化扩容与多模态视觉截图（`desktop_screenshot`）：Linux AT-SPI 与 Windows UI Automation 树遍历上限提升至 500 个节点、深度 16 层，并支持 `filter` 按名称或角色大小写不敏感过滤；新增 `desktop_screenshot` 截取桌面或窗口图像，自动适配 OpenAI 视觉消息与 Anthropic 原生 `tool_result` 图像块。
- Windows 原生本地 `stdio` MCP 支持：通过匿名管道、受控环境变量块、`.exe`/`.cmd`/`.bat` 解析与 Job Object 生命周期绑定，在 Windows 10/11 上完整支持本地 `stdio` MCP 服务。
- 主动上下文摘要压缩（`/compact`）：在保留完整可滚动历史记录（`transcript`）不变的前提下，调用当前模型将长对话提炼为高密度续接摘要并同步至后台常驻工作进程，释放上下文窗口。

---

One-command turn rollback, 4 MB file editing, regex and `.gitignore`-aware search, smarter shell approvals, live command output progress, SSRF-safe web fetching, multimodal desktop screenshots, Windows local `stdio` MCP, and active `/compact` context summarization.

- Per-turn rollback (`/undo`) and automatic cache GC: tracks pre-turn file snapshots and newly created files so `/undo` atomically restores multi-edit turns and removes newly created files while automatically pruning stale `.desk-agent/backups` and `.desk-agent/clipboard` entries.
- 4 MB `edit_file` ceiling: sliced `read_file` calls include full-file `sha256` for files up to 4 MB, allowing `edit_file` to patch large source files safely with optimistic SHA256 locking while `write_file` retains its 256 KB full-rewrite guard.
- Regex, `file_pattern` globs, and `.gitignore` awareness: `search_text` adds `regex` and `file_pattern` (`*`, `?`, `{a,b}`) options, and `search_text`, `code_outline`, and `@file` completion honor workspace `.gitignore` rules.
- Smarter shell approval granularity: auto-edit mode (`--approval edit`) automatically allows strictly validated read-only inspection commands (rejecting pipes, redirects, and chaining), while interactive shell approvals add `[4] Allow similar` to remember a trusted command rule for the current chat.
- Live command output tail progress and `web_fetch`: commands running past 0.35s surface their latest output line in the live activity bar; `web_fetch` fetches public HTTPS documentation pages (with DNS SSRF blocking, `CURLOPT_RESOLVE` IP pinning, and built-in HTML-to-text extraction) behind user approval.
- Deeper desktop automation and `desktop_screenshot`: raises AT-SPI and Windows UIA traversal limits to 500 controls / depth 16 with optional `filter` matching, and adds `desktop_screenshot` wired natively for both OpenAI vision follow-ups and Anthropic `tool_result` image blocks.
- Windows local `stdio` MCP support: implements anonymous pipes, `.exe`/`.cmd`/`.bat` command resolution, clean environment blocks, and Job Object process cleanup for local `stdio` MCP servers on Windows 10/11.
- Active `/compact` context summarization: summarizes long conversations with the active model into a dense continuation brief and syncs it to persistent conversation workers while keeping the human-readable scrollback transcript intact.
