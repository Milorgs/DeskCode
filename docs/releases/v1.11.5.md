# DeskCode 1.11.5

对话输入更顺手，长时间使用更稳定。

- 调出之前的需求：在对话输入框按 `Ctrl+P` / `Ctrl+N`（或 `Alt+↑/↓`）逐条调出本对话之前发送的需求，可修改后再发；正在输入的草稿会在翻回最新一条之后恢复。`↑/↓` 仍用于滚动对话。
- 上下文占用：底部状态栏显示本轮请求占上下文预算的估算比例（如 `上下文约 37%（估算）`，按请求内容字节数估算，不是服务商报告的词元数），达到 80% 时变为提醒色，方便判断何时 `/clear` 或新建对话。
- 长对话输出不再重复刷屏：任务输出超过 64 KB 后不会把整段旧内容反复写进对话；重新打开已完成的对话时，回复只显示一次。
- 非法或被截断的 UTF-8 输出显示为替换字符，不再让对话停止更新；`--verbose` 下的命令输出按字符边界截断并过滤终端控制序列。
- 审批选项显示期间调整窗口大小，选项行留在输入行；窗口缩到很小时收到的消息在恢复后仍保留在对话里。
- Markdown：行内代码中的 `**` 原样显示；代码块只在相同栏符、长度不少于开栏时闭合，四反引号里嵌套的代码块显示正确。✅ ❌ 🚀 等宽 emoji 按两格计算，避免对话区错位。
- OpenAI 接口的流式请求会要求返回用量，词元统计不再为 0；Anthropic 流式用量合并输入与输出。某服务商或模型不接受该参数时自动去掉重试一次，不影响其他服务商与模型。
- 引导审批模式下单独发送数字不会被当作审批回答；排队、错误提示写进对话而不是压在输入框边框上；界面运行时忽略 `Ctrl+Z`，避免挂起后终端残留鼠标和滚动区域状态。

---

Smoother chat input and steadier long sessions.

- Recall earlier requests: press `Ctrl+P` / `Ctrl+N` (or `Alt+Up/Down`) in the chat input to step through requests sent in this conversation and edit them before resending; the draft you were typing comes back after the newest entry. `Up/Down` still scroll the conversation.
- Context usage: the status line shows an estimate of how much of the context budget the latest request used (for example `Context ~37% (est.)`, based on request bytes rather than provider-reported tokens), highlighted from 80%, so you know when to `/clear` or start a new chat.
- No more repeated output: once a task's output exceeds 64 KB, earlier text is no longer written into the conversation again and again, and reopening a finished chat shows each reply once.
- Invalid or truncated UTF-8 in output shows replacement characters instead of freezing the conversation; command output in `--verbose` is cut on character boundaries and stripped of terminal control sequences.
- Resizing the window while approval choices are shown keeps them on the input row; messages received while the window is too small for the chat frame are kept and shown again when it grows.
- Markdown: `**` inside inline code stays literal; code fences close only on the same fence character with at least the opening length, so nested fences inside a four-backtick block render correctly. Wide emoji such as ✅ ❌ 🚀 count as two cells, preventing misaligned rows.
- OpenAI streaming requests ask for usage, so token counts are no longer zero; Anthropic streaming usage combines input and output tokens. An endpoint and model that reject the option get one automatic retry without it while other providers and models keep requesting usage.
- In guided approval mode a lone digit is never taken as an approval answer; queue and error notices go into the conversation instead of over the input frame; `Ctrl+Z` is ignored while the interface runs so the terminal is not left with mouse reporting and a scroll region after suspending.
