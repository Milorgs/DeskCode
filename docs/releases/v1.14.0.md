# DeskCode 1.14.0

对标 Claude Code 与 Codex CLI 补齐全部六项深水区能力：Linux Landlock 内核级命令沙箱、内置 `web_search` 联网搜索、单文件多区块原子批量编辑（`multi_edit`）、生命周期钩子（`Hooks`）与自定义斜杠指令（`.desk-agent/commands/` & `.claude/commands/`）、Anthropic 原生 `cache_control` 提示词缓存断点，以及 macOS 跨平台支持。

- Linux Landlock 内核级文件系统沙箱：在 Linux 5.13+ 内核上默认对 `run_shell` 子进程施加无特权 Landlock 规则（支持 ABI v1–v3 `REFER` 与 `TRUNCATE`），在内核态将文件写入、创建、删除与截断权限严格限制在当前工作目录（`workspace`）、`/tmp` 及基础设备节点内，彻底阻断命令越界修改 `$HOME`、`~/.ssh`、`~/.config/desk-agent` 或其他仓库；可通过 `/sandbox`、`--no-sandbox` 或 `DESK_NO_SANDBOX=1` 按需切换，并在 `desk doctor` 与 `/status` 中显示状态。
- 内置免密钥联网搜索（`web_search`）：新增关键词联网搜索工具，直接返回网页标题、解码后的真实链接与摘要，配合 `web_fetch` 构成「关键词检索 -> 阅读正文」两阶段查资料闭环；支持通过 `DESK_SEARCH_URL` 接入本地 SearXNG 或自定义搜索接口，共享 DNS SSRF 私网拦截保护。
- 单文件多区块原子批量编辑（`multi_edit`）：支持在一次工具调用中对单个最大 4 MB 的文件提交 1–20 处 `{old_text, new_text}` 替换，统一校验一次 `expected_sha256`、生成合并彩色 diff 预览、只产生一次审批与一份 `.bak` 备份；任一区块匹配失败或有歧义时精确返回 `failed_edit_index` 与 `match_lines` 且原文件零改动，配合 `/undo` 可一键完整回滚。
- 生命周期钩子（`Hooks`）、`DESKCODE.md` 项目约定与自定义斜杠指令：项目约定文件正式升级为原生 `DESKCODE.md` / `deskcode.md`（并向下兼容 `AGENTS.md`）；支持在 `<config_dir>/hooks.json` 或受审批保护的 `.desk-agent/hooks.json` 中配置 `pre_shell`（执行前策略拦截）与 `post_edit`（写盘后自动运行格式化/Linter/语法检查并将 `hook_output` 实时回传给模型自修复）；同时支持 `.deskcode/commands/*.md`、`.desk-agent/commands/*.md` 与用户级 `commands/*.md` 自定义斜杠模板（支持 `$ARGUMENTS` 参数展开与 `/commands` 列表查看）。
- Anthropic 原生提示词缓存（Prompt Caching）：在 Anthropic 协议请求中自动为 `system`、工具列表末尾与最新用户消息打上 `cache_control: {"type": "ephemeral"}` 断点，大幅降低多步工具调用的输入词元开销与首字延迟；遇到不支持该字段的第三方兼容网关返回 HTTP 400 时按「服务商+模型」自动无感回退。
- macOS 跨平台适配：补齐 macOS 下的伪终端（`util.h`）、可执行路径解析（`_NSGetExecutablePath`）、`NSPasteboard` 剪贴板贴图、`screencapture` 桌面截图、`System Events` 桌面无障碍交互与 CMake/Make 构建支持，一套源码同时覆盖 Linux、Windows 与 macOS。

---

Closing the remaining architectural gaps with Claude Code and Codex CLI: Linux Landlock kernel sandboxing, built-in `web_search`, atomic multi-hunk `multi_edit`, lifecycle `Hooks` and custom slash commands, Anthropic `cache_control` prompt caching, and macOS portability.

- Linux Landlock kernel sandbox: `run_shell` child processes on Linux 5.13+ are restricted by unprivileged Landlock rules (ABI v1–v3 including `REFER` and `TRUNCATE`) so writes, creations, deletions, and truncations outside the workspace and `/tmp` are blocked directly by the kernel; toggleable via `/sandbox`, `--no-sandbox`, or `DESK_NO_SANDBOX=1` and surfaced in `desk doctor` and `/status`.
- Built-in `web_search`: keyword web search returning clean titles, unwrapped target URLs, and snippets (with optional `DESK_SEARCH_URL` for local SearXNG/JSON endpoints and shared SSRF private-IP blocking), pairing seamlessly with `web_fetch`.
- Atomic multi-hunk `multi_edit`: applies 1..20 `{old_text, new_text}` hunks in a single transaction against one `expected_sha256` check, one combined diff preview, and one `.bak` undo snapshot, reporting `failed_edit_index` and `match_lines` without touching disk if any hunk fails.
- Lifecycle `Hooks`, `DESKCODE.md`, and custom slash commands: promotes `DESKCODE.md` / `deskcode.md` as the primary workspace instruction file (with `AGENTS.md` compatibility), supports `pre_shell` policy guards and `post_edit` linter/compiler/formatter hooks (`hooks.json`, feeding `hook_output` and `hook_exit_code` straight back to the model; workspace hooks require user approval), and supports `.deskcode/commands/*.md` and `.desk-agent/commands/*.md` prompt templates (`$ARGUMENTS` expansion and `/commands` listing).
- Native Anthropic Prompt Caching: automatically attaches `cache_control: {"type": "ephemeral"}` breakpoints across `system`, `tools`, and the latest `user` turn, with per-provider/per-model HTTP 400 fallback for non-supporting gateways.
- macOS cross-platform support: adds macOS PTY/process portability, `NSPasteboard` clipboard images, `screencapture` desktop screenshots, `System Events` UI inspection/actions, and CMake/Makefile build support across Linux, Windows, and macOS.
