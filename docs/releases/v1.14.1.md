# DeskCode 1.14.1

此版本汇总 1.12.0 之后的改进。本次新增两项修复：

- Linux 启用 Landlock 时，如果规则创建、配置或应用失败，DeskCode 会停止执行命令并显示错误。允许写入的临时目录仍为 /tmp。
- /undo 部分撤回失败时，会列出未恢复的文件并保留相应记录与备份。修复文件或权限问题后可重试，已经成功处理的文件不会再次撤回。

本版还包含批量编辑、项目钩子、自定义命令、网页搜索、桌面截图及 Windows 本地 stdio MCP 支持。完整改动见 [1.13.0](https://github.com/Milorgs/DeskCode/blob/main/docs/releases/v1.13.0.md) 和 [1.14.0](https://github.com/Milorgs/DeskCode/blob/main/docs/releases/v1.14.0.md) 的版本说明。

---

This release includes changes since 1.12.0 and adds two fixes:

- With Landlock enabled on Linux, commands stop with an error if the sandbox cannot be created, configured, or applied. The writable temporary directory is /tmp.
- If /undo only partly succeeds, it lists the unresolved paths and retains their records and backups. A retry skips the files already handled.

This release also includes multi-edit, project hooks, custom commands, web search, desktop screenshots, and local stdio MCP on Windows. See the [1.13.0](https://github.com/Milorgs/DeskCode/blob/main/docs/releases/v1.13.0.md) and [1.14.0](https://github.com/Milorgs/DeskCode/blob/main/docs/releases/v1.14.0.md) notes for the full changes.
