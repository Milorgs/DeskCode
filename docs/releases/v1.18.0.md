# DeskCode 1.18.0

此版本攻克最后三大底层深水区能力：**三平台内核级沙箱 + 子进程网络隔离**、**`desk serve` 多端共享会话守护进程与内置 Web 控制台 + 原生系统桌面通知**，以及 **MCP 全协议补齐（`resources`、`prompts` 与 OAuth 2.0 + S256 PKCE 自动刷新）**。

- **三平台内核级沙箱 + 网络隔离（`--no-net`、`/sandbox [net]`、`desk doctor`）**：
  - **Linux（Landlock + Seccomp-BPF）**：默认通过 Landlock ABI v1–v3 限制工作区与 `/tmp` 之外的文件写入（现已自动识别 Git Worktree 共享 `.git` 元数据目录，在锁死主检出目录只读的同时放行 Worktree 内 `git commit`）；开启 `--no-net` 或 `/sandbox net` 时通过内核 **Seccomp-BPF** 拦截子进程及孙进程的 `socket(AF_INET / AF_INET6)` 调用，无需 root 或用户命名空间即可彻底断网并保留本地管道与 Unix 套接字。
  - **macOS（Apple Seatbelt / `sandbox-exec`）**：原生生成 SBPL 沙箱策略，阻断工作区、临时目录与设备节点之外的一切 `file-write*`，并在 `--no-net` 下追加 `(deny network* (remote ip))` 内核级禁网。
  - **Windows（Job Object UI/进程上限 + Restricted Token）**：通过 `CreateRestrictedToken(DISABLE_MAX_PRIVILEGE)` 剥离危险特权，并结合内核 Job Object 施加 64 进程防炸弹上限与 `JOBOBJECT_BASIC_UI_RESTRICTIONS`（禁止子进程读写系统剪贴板、跨窗口句柄注入或退出会话），支持 `--no-net` 网络封锁。
- **`desk serve` 多端共享会话守护进程、内置 Web 控制台、`desk attach` 与原生系统桌面通知（`src/serve.cpp`）**：
  - **`desk serve [--host 127.0.0.1] [--port 7890] [--token 密钥]`**：零外部依赖的跨平台多线程 HTTP + 实时 **SSE（`text/event-stream`）** 守护服务端，内置响应式深色 **Web 控制台**（`GET /`），支持多浏览器标签页、终端与 Python SDK `DeskServeClient` 同时挂载**同一个实时会话**（流式推理分块、工具卡片、四档模式切换、禁网沙箱开关，以及**跨客户端远程点击批准/拒绝**）。非回环地址监听自动强制生成随机 Bearer 令牌并做常量时间校验与 Origin 防护。
  - **`desk attach [URL] [--session ID] [-p 需求] [--approve allow|deny]`**：从任意终端连接正在运行的 `desk serve` 共享会话发送需求、实时流式打印回复或远程审批待确认操作。
  - **三端原生桌面通知（`--notify`、`/notify`、`DESK_NOTIFY=1`）**：当后台挂起对话或 `desk serve` 会话完成任务或暂停等待批准时，自动调用 Linux `notify-send`、macOS `osascript`（参数隔离零注入）或 Windows 系统气泡通知提醒用户。
- **MCP 全协议补齐：`resources`、`prompts` 与 OAuth 2.0 + S256 PKCE（`src/mcp.cpp`）**：
  - **Resources 与 Prompts**：支持连接仅声明 `resources` 或 `prompts` 能力的 MCP 服务；按需挂载只读工具 `mcp_list_resources`、`mcp_read_resource` 与 `mcp_get_prompt`（Plan 模式下同样安全可用），并支持在对话中直接输入 `/<服务名>:<提示名> [key=val]` 展开远程 MCP 提示模板。
  - **OAuth 2.0 + S256 PKCE 与自动刷新（`desk mcp`）**：新增 `desk mcp list | auth <服务名> | token <服务名> <令牌> | logout <服务名>`；`desk mcp auth` 原生支持 RFC 8414 `.well-known/oauth-authorization-server` 自动发现、RFC 7591 动态客户端注册、RFC 7636 `S256` PKCE 与本地回环回调监听，凭据以 `0600` / Windows 私有 ACL 保存在 `mcp_tokens.json`，并在令牌临期时通过 `refresh_token` 自动无感续期。

---

This release delivers three foundational capabilities: **three-platform kernel sandboxing with optional network isolation**, the **`desk serve` multi-client shared session daemon + built-in Web console + native desktop notifications**, and **complete MCP support (`resources`, `prompts`, and OAuth 2.0 + S256 PKCE with automatic token refresh)**.

- **Three-Platform Kernel Sandbox + Network Isolation (`--no-net`, `/sandbox [net]`, `desk doctor`)**:
  - **Linux (`Landlock` + `Seccomp-BPF`)**: Landlock ABI v1–v3 restricts filesystem writes to the workspace, worktree `.git` metadata, and `/tmp`, while `--no-net` / `/sandbox net` installs an unprivileged **Seccomp-BPF** filter blocking `socket(AF_INET | AF_INET6)` across child and grandchild processes while preserving local pipes and Unix sockets.
  - **macOS (`Seatbelt` / `sandbox-exec`)**: Enforces kernel SBPL `file-write*` confinement to the canonical workspace and temporary directories, plus `(deny network* (remote ip))` when `--no-net` is active.
  - **Windows (`Job Object` + `Restricted Token`)**: Strips privileges via `CreateRestrictedToken(DISABLE_MAX_PRIVILEGE)`, enforces a 64-process cap and `JOBOBJECT_BASIC_UI_RESTRICTIONS` (blocking clipboard snooping, cross-process window handle attacks, and display/session changes), and locks down outbound proxy/WebRequest networking under `--no-net`.
- **`desk serve` Shared-Session Daemon, Web Console, `desk attach` & Native Desktop Notifications (`src/serve.cpp`)**:
  - **`desk serve [--host 127.0.0.1] [--port 7890] [--token SECRET]`**: Cross-platform HTTP + live **SSE (`text/event-stream`)** daemon with a built-in dark-mode **Web Console** (`GET /`), allowing browsers, terminals (`desk attach`), and Python SDK `DeskServeClient` to share live sessions, stream output, switch modes, and approve or deny pending operations remotely across clients.
  - **Native OS Notifications (`--notify`, `/notify`, `DESK_NOTIFY=1`)**: Dispatches native notifications via `notify-send` (Linux), `osascript` argv-safe notification (macOS), and Windows system notifications when background chats or `desk serve` turns complete or await approval.
- **Complete MCP Protocol: `resources`, `prompts` & OAuth 2.0 + S256 PKCE (`src/mcp.cpp`)**:
  - **Resources & Prompts**: Connects to MCP servers advertising any combination of `tools`, `resources`, and `prompts`; exposes Plan-Mode-safe `mcp_list_resources`, `mcp_read_resource`, and `mcp_get_prompt` on demand, plus `/<server>:<prompt> [key=val]` slash expansion in chat.
  - **OAuth 2.0 + S256 PKCE (`desk mcp`)**: Added `desk mcp list | auth <server> | token <server> <tok> | logout <server>` with RFC 8414 `.well-known/oauth-authorization-server` discovery, RFC 7591 dynamic client registration, loopback PKCE callback, `0600`/ACL `mcp_tokens.json` storage, and automatic `refresh_token` rotation.
