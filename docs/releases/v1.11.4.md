# DeskCode 1.11.4

此版本汇总 1.10.11 之后的改进，继续使用 C++ 终端界面。

- 回复支持流式 Markdown 排版；文件改动审批展示彩色 diff。
- 对话右侧显示比例滚动条，支持按住拖动、移出轨道继续拖动及松开停止。滚轮和 Ctrl+↑/↓ 逐行移动；选择文字用 Shift+鼠标拖动。终端按字符行滚动，不是像素级平滑滚动。
- Ctrl+D 从对话和子菜单逐层返回；主菜单通过“退出”选项退出，避免误关程序。
- 新增服务商预设、在线模型选择、`desk -c`、`desk doctor`、标准输入需求和 `--json` 脚本输出。
- 改进上下文裁剪、文件分段读取、目录和文本搜索，以及 MCP 连接复用。
- 发布 Linux x86_64 与 Windows x64 安装包；滚轮和拖动说明适用于 Linux 终端。没有加入图形窗口，也不包含任何用户模型密钥或对话记录。

---

This release collects the improvements since 1.10.11 and retains the C++ terminal interface.

- Streaming Markdown replies and coloured file-diff approval previews.
- A proportional conversation scrollbar with drag capture, off-track dragging, and release handling. The wheel and Ctrl+Up/Down move by one row; use Shift+drag to select text. Terminal scrolling is row-based, not pixel-smooth.
- Ctrl+D returns from chats and submenus one level at a time. Use Exit on the main menu to close the program.
- Provider presets, live model selection, `desk -c`, `desk doctor`, stdin requests, and `--json` output for scripts.
- Improved context trimming, ranged file reads, directory/text searches, and MCP connection reuse.
- Linux x86_64 and Windows x64 packages. Mouse scrolling and dragging described above apply to Linux terminals. No graphical window, personal API keys, or conversation history is included.
