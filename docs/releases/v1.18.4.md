# DeskCode 1.18.4

## 中文

- 在对话中使用 F2 或 /model 选择模型，只更新该对话及其排队中的请求。重新打开对话后会恢复它的模型。
- 主菜单的模型选择决定新对话的默认模型。首页按模型列出累计词元，移除了当前模型标记。

## English

- F2 and /model change the model for the open conversation and its queued requests. Reopening a conversation restores its model.
- The home menu sets the default model for new conversations. The home screen lists cumulative token usage per model without highlighting a current model.
